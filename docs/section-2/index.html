    Inference-Scaling for Kernel Generation #

    Overview #

    This section studies how to get better kernels by spending more compute at generation time, holding the model fixed. We frame inference-time scaling along three axes, width (parallel best-of-N sampling), depth (sequential, feedback-conditioned refinement), and structured search (beam, tree, and evolutionary methods that maintain and improve populations of candidate kernels, including methods that search over how a kernel is decomposed into subproblems rather than over a monolithic artifact), plus an orthogonal reasoning-length knob. What makes all of this pay off for kernels is a cheap, automatic verifier: compile a candidate, check it against a reference, and time it, so we can always keep the best verified result. That single fact also makes the verifier the true bottleneck, so we devote a subsection to verification and cheating detection, the anti-hacking discipline that lets extra compute buy real speedups rather than reward hacking. The section closes with a live, follow-along demo that generates Neuron Kernel Interface (NKI) kernels for AWS Trainium using an agentic, training-free inference pipeline. The post-training machinery that produces the underlying policy is developed in Section 3.
