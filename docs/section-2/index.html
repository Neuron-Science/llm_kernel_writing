    Post-Training LLMs for Kernel Generation #

    Overview #

    This section applies the post-training machinery of Section 1 to kernels. We start with supervised fine-tuning on kernel corpora, which grounds a base model in a kernel language but is capped by the demonstrations it imitates. We then turn to reinforcement learning from execution feedback, which lets the model learn from compiling and timing its own kernels and so surpass that ceiling, and close with how such a reward is designed and how models learn to cheat it.

    Contents of this section #

    2.1 Supervised Fine-Tuning on Kernel Corpora #

    Building a (task, kernel) corpus, through sampling, filtering, and augmentation, and training a base model to imitate it, along with the limits of imitation.

    2.2 Reinforcement Learning from Execution Feedback #

    Casting kernel generation as RL: prompt-only tasks, the compile-correct-fast reward from running each kernel, and the curriculum that keeps training on solvable tasks.

    2.3 RL for Kernel Optimization and Reward Hacking #

    Designing the reward from execution signals, the ways models game it, and the verification pipeline that keeps the reward honest.
